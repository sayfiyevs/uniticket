Settings

The ATTO access token is not self-refreshing — copy a fresh one from your browser's DevTools (Network tab, any request to tickets.atto.uz) when scraping starts failing.

ATTO access token

Stored in web_settings.json next to the scripts, and passed to every scraping job as the ATTO_ACCESS_TOKEN environment variable. Leave blank to fall back to whatever's hardcoded in atto_scraper.py.

Database

Both atto_scraper.py and route_engine.py connect to a local SQL Server instance (DESKTOP-5K5RC72\\UzWayDB) using Windows integrated authentication — this app must run on that machine, or its domain, with ODBC Driver 17 for SQL Server installed. Edit the DB_CONNECTION_STRING constant at the top of both files to point elsewhere.
